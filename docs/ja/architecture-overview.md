# アーキテクチャ概要

このプロジェクトは、CERT-Cルールエンジンを持つVSCode拡張機能として実装する。

## 基本方針

- 初期対象C標準はC99とする。
- 解析コアはRustで実装し、WASMとしてTypeScript側から呼び出す。
- 外部解析ツールへの依存は初期設計に含めない。
- 組み込み環境差やコンパイラ拡張は、環境モデルファイルで表現する。
- VSCode拡張機能はUI、設定、コマンド、Problems表示を担当する。

## 構成

```text
VSCode Extension
  ├─ コマンド
  ├─ 設定
  ├─ ファイル探索
  ├─ 自動再解析制御
  └─ Problems表示

Rust/WASM Analyzer
  ├─ 字句解析
  ├─ プリプロセッサモデル
  ├─ Parser/AST
  ├─ ルールエンジン
  └─ 診断出力
```

Rust/WASM側は、WASM境界API、解析フロー、字句解析、診断モデル、ルール実装をモジュール分割する。
各CERT-Cルールの実装は`analyzer-wasm/src/rules/`以下へ配置する。

## 実装範囲

検出テスト用Cコードを通しで確認するための最小実装を行っている。

- `DCL37-C`
- `EXP31-C`
- `EXP45-C`
- `INT33-C`
- `PRE31-C`
