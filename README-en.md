## Overview

This is a prototype VSCode extension for running CERT-C-oriented checks.

The extension calls a Rust/WASM analyzer core from TypeScript and publishes detected diagnostics to VSCode Problems.
The project is in an early validation phase and will incrementally expand CERT-C rule support for C99.

## Features

- CERT-C-oriented checks for C source files and header files
- Diagnostics in VSCode Problems
- Manual workspace-wide checks
- Automatic reanalysis of the edited or saved file
- Detection with a Rust/WASM analyzer core, without relying on external analysis tools

## Usage

Run the following commands from the command palette:

- `CERT-C: ワークスペースをチェック`
- `CERT-C: 診断をクリア`

By default, `.c` and `.h` files are analyzed.

## Settings

```json
{
  "certC.fileGlobs": ["**/*.c", "**/*.h"],
  "certC.excludeGlobs": ["**/.git/**", "**/.svn/**", "**/.hg/**", "**/build/**", "**/cmake-build-*/**", "**/Debug/**", "**/Release/**", "**/dist/**", "**/vendor/**", "**/third_party/**"],
  "certC.analyzeOnChange": true,
  "certC.analyzeOnSave": true,
  "certC.analyzeDebounceMs": 500
}
```
